# Portfolio d’Edwar Nazzarian — GitHub Pages

Ce dossier est une version statique prête pour GitHub Pages. Il ne demande aucune installation ni compilation.

## Mise en ligne

1. Déposez **tout le contenu de ce dossier** à la racine du dépôt `edwarnazzarian.github.io`.
2. Dans GitHub, ouvrez **Settings → Pages**.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche `main`, le dossier `/ (root)`, puis **Save**.

Le site sera normalement accessible à l’adresse suivante :

`https://killua11111010100.github.io/edwarnazzarian.github.io/`

## Fichiers principaux

- `index.html` : contenu et structure du portfolio;
- `style.css` : design et adaptation téléphone/tablette/ordinateur;
- `script.js` : langue, thème, menu mobile, galerie, copie du courriel et navigation;
- `cv-edwar-nazzarian.pdf` : CV téléchargeable;
- `og.png` : aperçu lorsque le lien est partagé;
- `project-*.png` : captures des projets.

Tous les chemins sont relatifs afin que le portfolio fonctionne correctement dans un dépôt de projet GitHub Pages.
